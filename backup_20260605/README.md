# ⚔️ 兵器破阵 · 易经起卦

> 一款融合传统易经文化与现代游戏化体验的六爻起卦应用

## 📖 项目简介

「兵器破阵 · 易经起卦」是一款创新的易经占卜应用，将传统六爻起卦法与游戏化交互完美融合。用户通过选择不同兵器"破阵"的方式起卦，配合AI智能解卦，获得针对具体问题的详细卦象解读。

**核心特色：**
- 🎮 **游戏化交互** - 拖拽兵器破阵，铜钱摇卦动画，沉浸式体验
- 🤖 **AI智能解卦** - 接入DeepSeek大模型，四部分结构化详细解读
- 📱 **全平台支持** - 响应式设计，PC/手机无缝切换
- 🎯 **成长体系** - 道行等级、灵力系统、兵器解锁、成就收集
- 📊 **完整六爻** - 本卦、变卦、互卦，64卦完整数据

## 🎮 操作说明

### 基本流程

```
选择兵器 → 拖入八卦镜 → 输入问题 → 破阵起卦 → 查看卦象 → AI解卦
```

### 详细操作

#### 1️⃣ 选择兵器
- 顶部兵器栏展示可用兵器
- 每种兵器有不同的破阵成功率
- 初始只有「锈迹小刀」，随道行提升解锁更多

| 兵器 | 破阵率 | 解锁条件 |
|------|--------|----------|
| 锈迹小刀 | 60% | 初始解锁 |
| 精铁长剑 | 70% | 道行3级 或 破阵5次 |
| 柳叶飞刀 | 75% | 道行5级 或 破阵10次 |
| 屠龙刀 | 80% | 道行8级 或 破阵30次 |
| 倚天剑 | 85% | 道行10级 或 破阵50次 |

#### 2️⃣ 起卦破阵
- **拖拽操作**：将兵器拖动到中央八卦镜
- **触摸操作**：长按兵器，拖动到八卦镜
- 破阵成功后进入铜钱摇卦动画

#### 3️⃣ 输入问题
- 破阵成功后弹出问题输入框
- 可输入具体问题（如"今日运势如何？"）
- 也可跳过直接起卦

#### 4️⃣ 查看结果
- **卦象信息**：本卦、变卦、互卦名称和符号
- **AI解卦**：四部分详细解读
  - 📖 本卦详解
  - 🔗 互卦分析
  - 🎯 针对问题断吉凶
  - 💡 行动提点

## 🌟 功能介绍

### 核心功能

#### 🔮 六爻起卦系统
- 采用传统「三枚铜钱法」起卦
- 每摇一次生成一爻，共六爻成卦
- 支持动爻，自动计算变卦和互卦
- 64卦完整数据（卦辞、大象、爻辞）

#### 🤖 AI智能解卦
- 接入DeepSeek大语言模型
- 结构化四部分解读：
  1. **本卦详解** - 卦名含义、卦辞释义、大象寓意
  2. **互卦分析** - 事情发展中段过程和内在因素
  3. **针对问题断吉凶** - 明确结论，分情况说明
  4. **行动提点** - 具体行动建议和注意事项

#### 🎮 游戏化系统

**道行等级**
- 每次成功起卦获得经验值
- 等级提升解锁新兵器
- 等级影响破阵成功率

**灵力系统**
- 每次起卦消耗灵力
- 签到、任务获得灵力
- 灵力不足无法起卦

**兵器强化**
- 消耗灵力强化兵器
- 提升破阵成功率
- 强化等级上限随道行提升

**成就系统**
- 累计起卦次数成就
- 连续签到成就
- 特殊事件成就

### 辅助功能

#### 📋 每日任务
| 任务 | 条件 | 奖励 |
|------|------|------|
| 问道一次 | 完成1次起卦 | 灵力+2，经验+5 |
| 问道三次 | 完成3次起卦 | 灵力+5，经验+10 |
| 王者之兵 | 使用王者兵器破阵 | 灵力+3，经验+15 |
| 破阵成功 | 成功破阵1次 | 灵力+2，经验+8 |

#### 🌅 今日运势
- 每日自动生成运势
- 包含运势等级、建议、幸运色、方位、数字
- 连续签到提升运势加成

#### 📚 八卦知识库
- 完整64卦查询
- 支持卦名搜索
- 卦辞、大象、爻辞详解

#### 📅 签到系统
- 每日签到获得奖励
- 连续签到额外加成
- 签到记录持久化

## 🏗️ 技术架构

### 前端技术
- **原生HTML/CSS/JavaScript** - 无框架依赖，轻量高效
- **Canvas粒子系统** - 破阵特效、火焰碎片
- **Web Audio API** - 音效合成
- **响应式设计** - 自适应PC/手机屏幕
- **触摸事件支持** - 完整移动端交互

### 后端技术
- **FastAPI** - 高性能异步Web框架
- **SQLite** - 轻量级数据库，数据持久化
- **DeepSeek API** - AI智能解卦
- **RESTful API** - 标准化接口设计

### 数据库设计
```
users          - 用户信息（等级、灵力、签到）
weapons        - 兵器状态（解锁、强化等级）
divinations    - 起卦记录（卦象、问题、解读）
achievements   - 成就记录
daily_stats    - 每日统计
daily_tasks    - 每日任务进度
```

## 🔧 配置说明

### AI解卦配置
在 `server.py` 中设置DeepSeek API密钥：

```python
DEEPSEEK_API_KEY = "your_api_key_here"
```

获取API密钥：https://platform.deepseek.com/

### 服务端口
默认端口8000，可在 `server.py` 底部修改：

```python
uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 🎯 使用建议

### 起卦时机
- 心诚则灵，起卦前静心冥想
- 问题越具体，解读越精准
- 同一问题不宜反复起卦

### 问题示例
- ✅ "今日运势如何？"
- ✅ "这个项目能否成功？"
- ✅ "近期是否适合投资？"
- ❌ "明天会发生什么？"（过于宽泛）
- ❌ "我该怎么做？"（缺少具体情境）

### 提升体验
- 连续签到提升运势
- 完成任务获取灵力
- 解锁高级兵器提高成功率

## 📜 卦象说明

### 六爻基础
- **本卦** - 当前状态，起卦所得
- **变卦** - 未来趋势，动爻变化后
- **互卦** - 内在因素，中间过程

### 爻象含义
| 爻象 | 符号 | 含义 |
|------|------|------|
| 老阳 | ━━━ O | 阳极生阴，动爻 |
| 少阳 | ━━━ | 阳爻，稳定 |
| 少阴 | ━ ━ | 阴爻，稳定 |
| 老阴 | ━ ━ X | 阴极生阳，动爻 |
